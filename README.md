# Лабораторна робота №3 — Гра «Лабіринт» (Android / Kotlin)

## Виконання вимог завдання
1. **Мова розробки**: Kotlin (Android SDK 34, сумісність з JDK 17).
2. **Git та `.gitignore`**: Налаштовано повний `.gitignore` для Android/Gradle/Kotlin та сформовано логічну історію комітів.
3. **Логування (`Logger`)**: Реалізовано синглтон `AppLogger` (`java.util.logging.Logger` із кастомним `Formatter` та `ConsoleHandler` + інтеграція з `android.util.Log`), який логує генерацію лабіринту, кожен хід гравця, зіткнення зі стінами, перемикання мов та проходження рівнів.
4. **Інтернаціоналізація (`i18n`)**: Повна підтримка української (`values-uk/strings.xml`) та англійської (`values/strings.xml`) локалей із миттєвим перемиканням у реальному часі через `AppCompatDelegate.setApplicationLocales()`.
5. **Ігрова механіка «Лабіринт»**: Алгоритм *Recursive Backtracker (DFS)* генерує унікальний прохідний лабіринт на кожному рівні. Керування підтримує як свайпи по екрану, так і екранні кнопки.
